## Scope of this project's MIT license

The MIT license in `LICENSE` covers **this project's own source code only** —
`router/`, `translator/` (including `profiles.py` and `lua_host.py`),
`plugins/lua/ualc_sdk.lua`, `integration_contract.py`, `testing_infra/`,
`devices/`, `schemas/`, `examples/` and `docs/`. It does not cover, and does
not relicense, any third-party dependency.

(This note previously lived at the end of `LICENSE` itself, which caused
GitHub to report the repository license as `NOASSERTION` / "Other" rather than
MIT. For a project that asks for outside contributions, a correctly detected
license matters, so `LICENSE` is now the verbatim MIT text and the scope note
lives here.)

### Community contributions

Contributions are accepted under MIT (inbound = outbound, no CLA). Community
Lua plugins and model profiles must be MIT-compatible — see `CONTRIBUTING.md`.

Reimplementing a documented wire format is fine; a protocol is not a
copyrightable expression. Copying another project's decoder, its comments or
its captured fixtures is not, and GPL-licensed sources are incompatible with
this project. Where protocol knowledge was derived from another project,
provenance is recorded in the contribution itself:

- `plugins/lua/examples/lg_air_910604_ww/` and `devices/lg/AIR_910604_WW.json`
  — LG ThinQ2 TLV framing and tag numbers. Independently implemented from a
  documented field list; corroborated by public reverse-engineering discussion
  in `anszom/rethink` (GPL-2.0). **No code, comment text or captured fixture
  from that project was copied.** Its fixtures are deliberately not reused:
  the fixtures here are synthetic, generated by this repository's own encoder.
